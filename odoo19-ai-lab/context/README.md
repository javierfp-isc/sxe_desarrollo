# Contexto del agente

Este directorio contiene contexto pequeño, seleccionado y mantenible. No vuelques aquí los repositorios OCB/OCA.

## Estrategia recomendada
1. `AGENTS.md`: reglas generales, siempre disponibles.
2. `context/odoo19/`: fichas breves de conceptos necesarios para esta práctica.
3. `context/oca/`: repositorios y módulos candidatos, no documentación completa.
4. `context/tasks/`: instrucciones específicas por fase; incorpora solo la ficha de la fase actual.
5. `references/index.md`: archivos reales consultados, con ruta y commit.

## Context packs
Para cada tarea, crea un paquete breve con:
- Objetivo y preguntas.
- Rutas exactas a inspeccionar.
- Símbolos/XML IDs que se deben verificar.
- Extractos mínimos o resumen con referencias.
- No más contexto del necesario.

El agente debe consultar el fuente original cuando necesite confirmar detalles; el resumen no sustituye la fuente.
